CREATED STRUCTURE:
─────────────────────────────────────────────────────────────────────────────

resources/views/
│
├── layouts/
│   └── app.blade.php ........................... Main layout template
│                                               • Defines HTML structure
│                                               • Includes header & footer
│                                               • @yield('title')
│                                               • @yield('content')
│                                               • @yield('extra-styles')
│
├── components/
│   ├── header.blade.php ........................ Navigation bar
│   │                                           • Logo
│   │                                           • Nav links
│   │
│   └── footer.blade.php ........................ Footer
│                                               • Copyright
│                                               • Dynamic year
│
└── pages/
    ├── home.blade.php .......................... Home page
    │   @extends('layouts.app')
    │   @section('title', 'Home - Lock In App')
    │   @section('content') ... @endsection
    │
    ├── about.blade.php ......................... About page
    │   @extends('layouts.app')
    │   @section('title', 'About - Lock In App')
    │   @section('content') ... @endsection
    │
    └── services.blade.php ...................... Services page
        @extends('layouts.app')
        @section('title', 'Services - Lock In App')
        @section('content') ... @endsection
        @section('extra-styles') ... @endsection [Custom CSS]


HOW IT WORKS:
─────────────────────────────────────────────────────────────────────────────

Each page follows this pattern:

    @extends('layouts.app')
         ↓
    Inherits layout HTML structure
         ↓
    @section('title', 'Page Title')
         ↓
    Fills @yield('title') in layout
         ↓
    @section('content')
    ... page content ...
    @endsection
         ↓
    Fills @yield('content') in layout
         ↓
    Final HTML rendered with layout + page content


BLADE FEATURES USED:
─────────────────────────────────────────────────────────────────────────────

✓ @extends('layouts.app')     → Inherit parent layout
✓ @section('name')             → Define section in child
✓ @endsection                  → Close section
✓ @yield('name')               → Placeholder in parent
✓ @include('components.header') → Include reusable components
✓ {{ }}                        → Echo expressions
✓ {{ date('Y') }}              → PHP functions

BENEFITS:
─────────────────────────────────────────────────────────────────────────────

✓ DRY Principle: Header & footer defined once, used everywhere
✓ Maintainable: Update layout once, affects all pages
✓ Scalable: Add new pages easily by extending the layout
✓ Clean: Clear separation of concerns (layout, components, pages)
✓ Reusable: Components can be used in multiple layouts
✓ Flexible: Per-page custom styles via @section('extra-styles')

ADDING NEW PAGES:
─────────────────────────────────────────────────────────────────────────────

Create resources/views/pages/new-page.blade.php:

    @extends('layouts.app')
    @section('title', 'New Page - Lock In App')
    @section('content')
        <h1>Welcome to New Page</h1>
        <!-- Your content -->
    @endsection

Add route to routes/web.php:

    Route::get('/new-page', function () {
        return view('pages.new-page');
    });

Done! Header & footer automatically included.
